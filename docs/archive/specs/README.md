# Original design specifications

The briefs the platform was built from, verbatim. They state the constraints
that everything later descends from — point-in-time correctness, honest empty
states, deterministic code owning every decision that matters, and execution
that requires a human.

Read these to understand *why* a rule exists when the code's own comment is not
enough. They are historical: where a spec and the code disagree, the code and
the tests are authoritative.
