1. Objective of This Upgrade

The primary goal of this iteration is:

Transform the platform from a technically explainable trading engine into a professionally understandable decision system where a user can clearly distinguish deterministic market-data calculations, LLM-generated interpretation, portfolio/risk constraints, and the final trading decision.

The platform should answer five questions clearly:

1. What is the market data saying?
2. What exactly caused the Bull/Bear score?
3. What is the LLM saying based on news/catalysts?
4. Why is the system recommending Stock / Call / Put / No Trade?
5. What happens if the user applies this plan?

The system must never present an opaque:

AI Confidence = 92%

without explainability.

4. Bull Score / Bear Score Formula

Make the Score calculation explicit.

Conceptually:

Bull Score =
100 × weighted triggered bullish conditions
      --------------------------------------
           total bullish weight

and:

Bear Score =
100 × weighted triggered bearish conditions
      --------------------------------------
           total bearish weight

Then:

Directional Edge = Bull Score - Bear Score

Example:

Bull Score         77.8
Bear Score         11.1
Directional Edge  +66.7

The UI must make it immediately understandable why:

77.8 - 11.1 = +66.7

Do not require the user to reverse-engineer this.
